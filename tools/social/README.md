# La Horda social content factory — phase 1
Run Actions > Social content factory > Run workflow.
This workflow records the published game browser session in vertical format, saves a screenshot, transcodes a candidate MP4 and uploads review artifacts three times per week.
**It does not guarantee gameplay**, automatically select highlights, upload to Runway, or post to Metricool. Candidate videos require visual validation before publishing. No credentials are stored. Next integration: verified gameplay navigation, clip scoring, durable media hosting, then Metricool scheduling with a secret-managed API bridge. Runway is optional and requires user account connection.
