# Ronda 2 — instrucciones del Evaluador al Pintor

### gaze
- el cuerpo de la zona casi no se ve (0% del interior): subir el relleno trameado  → perilla `fill`: +0.06
- más marcas internas para dar cuerpo  → perilla `ticks`: +4
- poco detalle interior (0%): más marcas propias (estelas, hilos, runas)  → perilla `ticks`: +4
- estelas más gruesas para que se lean de lejos  → perilla `thick`: +1
- marcas más largas  → perilla `tick_len`: +0.04
- usar los 5 tonos de la rampa (falta luz o brillo)  → perilla `highlight_arc`: fijar 1
- agregar destello de impacto  → perilla `flash`: +0.2
- agregar destellos brillantes (tono 5)  → perilla `sparks`: +2
- activar el motivo temático del guardián (el arte actual lo tiene)  → perilla `motif_on`: fijar 1
- el arte actual tiene más trama temática: motivo más denso  → perilla `motif_n`: +1
- el arte actual tiene más trama interior: sumar marcas propias  → perilla `ticks`: +4
- el arte actual tiene más presencia central: glifo más grande  → perilla `glyph_scale`: +1
- probar otra familia de marcas  → perilla `deco`: pasar a la siguiente familia
- el arte actual tiene más cuerpo: subir el relleno trameado (techo del motor 24 %)  → perilla `fill`: +0.06
- el arte actual tiene más trama: sumar marcas  → perilla `ticks`: +2
- el arte actual tiene más presencia: borde más grueso  → perilla `rim`: +1
  aplicado: fill: 0.0 → 0.03; fill: 0.03 → 0.09; ticks: 0 → 2; ticks: 2 → 6; ticks: 6 → 10; ticks: 10 → 12; thick: 1 → 2; flash: 0.30000000000000004 → 0.5; sparks: 0 → 1; motif_n: 5 → 6; glyph_scale: 1 → 2; deco: 0 → 1; rim: 1 → 2
