# Skin del set «Caravana de Medianoche» — Ilkan

> INTEGRADA (rework de Ilkan, `docs/ILKAN_REWORK.md`). El arte es procedural (código propio, sin recursos de terceros):
> `python3 tools/art/ilkan/build.py` regenera `assets/sprites/champions/ilkan/skins/legion/{atlas,colossus,preview}.png`
> y los efectos de habilidad de `assets/vfx/skins/legion/`. Se ve con el set COMPLETO equipado.

- **Set:** `legion` (id interno conservado por compatibilidad de guardados) · Ilkan · lanzas de pendón · el Coloso de Arena · aura rgb(90,220,205)
- **Campeón:** Ilkan (`ilkan`) — el set solo lo puede usar este campeón
- **Se activa:** con el set COMPLETO (4 piezas). Con menos piezas solo hay aura parcial.
- **Bonus completo:** COLOSO ETERNO: el Coloso de Arena dura 30% más y cada baja transformado te cura 2% de la vida.
- **Reinterpretación real (no un recolor):** capa índigo con vivo plateado, faroles de cristal colgados del cinto, hombrera
  plateada; el Coloso pasa a ser de cristal azul con núcleo violeta. Misma grilla de animaciones que el atlas base.

## Piezas del set

- **Hoces de la Caravana** (arma) · **Arnés de Faroles** (pechera) · **Empuñaduras de Cristal** (guantes) · **Botas de Arena** (botas).
  Lore: «Cada farol de cristal guarda la última luz de una caravana que no llegó. Quien los lleva promete cruzar por ella.»
